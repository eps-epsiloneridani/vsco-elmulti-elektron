# VS Chamber Orchestra: Community Edition - converted to elmulti

Using [Asatamax's elmulti conversion tool](https://www.elektronauts.com/t/tonverk-tool-elmconv-exs24-sfz-to-elmulti-multi-sample-converter/243807), I have run it against the [VS Chamber Orchestra: Community Edition](https://versilian-studios.com/vsco-community/) which gives 3gb of orchestral sounds usable in the Tonverk multiplayer machine.
